# Workspace 知识库阅读器

[共用应用](../../workspaces/knowledge-preveiw-docs/README.md) 在启动时绑定一个业务工作区，直接展示知识、双语对照和被引用证据。源文件保持权威且只读；构建产物为派生快照。应用目录自身不是品牌工作区。

行为与接口见[已批准计划](../plans/2026-10-22-workspace-knowledge-reader-plan.md)，执行进展见[任务](../tasks/2026-10-22-workspace-knowledge-reader.md)，实际检查和限制见[记录](../records/2026-10-22-workspace-knowledge-reader-record.md)。阅读器不代表知识批准、发布或 GEO 业务效果。

本地适配、更新/隔离、构建快照及桌面/窄屏验收已完成，证据范围以 Record 为准。
