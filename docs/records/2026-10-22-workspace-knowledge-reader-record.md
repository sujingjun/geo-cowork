### 临时工作区运行验收

1. 修改英文后，已打开的中文页自动刷新并提示过期。
2. 新增文件后，当前页面导航自动出现新条目，可点击并通过全文搜索找到。
3. 删除当前文件后自动出现缺页提示，恢复首页后搜索结果中不再有该文件。
4. 已打开的引用文本在源文件修改后自动刷新。
5. 停止 Alpha 并启动 Beta 后，Alpha 的页面和文件不再可访问。
6. 为 Beta 构建后移走原工作区，构建服务仍能展示首页和引用全文；快照中的 script 文本未执行。

## 首次失败与修复

- 类型检查发现附件元数据分支推断及 Nuxt kit 导入问题，已修复并重跑通过。
- 实际 Content AST 为 minimark 的 value 数组，且链接已经移除 .md；初版适配未覆盖，造成一级标题重复和正文链接未转换。已按安装版本的源码修复，补充真实结构回归测试并核对全部站内目标。
- 精确 KB ID 查询曾先命中其他条目的引用段落；增加精确 ID 的条目定位，其余搜索继续使用模板组件。
- 中文 Source SHA-256 长串导致窄屏横向溢出，已增加正文自动断行。
- 缺页恢复改为原生导航链接，避免依赖错误页脚本加载时机。
- 浏览器测试按实际 textbox 角色、异步导航完成条件及结果目标路径断言；CSV 的 DOM 文本允许浏览器换行归一，同时原文接口按字节核对，未改变源文件。
- 运行测试最初把强制导航与 Vite 重连重叠，已改为等待自动目录更新并通过页面入口操作；自动刷新要求保留，最终 6 个场景全部通过。

## 证据与使用边界

当次本地证据位于 `tmp/knowledge-preview/`：开发/构建浏览器结果、运行结果、构建日志、业务文件 hash 比较和桌面/窄屏截图。可重复运行的确定性与运行验收代码随仓库维护；真实 MyyShop 浏览器脚本仅作为当次只读验收证据。

日常使用见[应用 README](../../workspaces/knowledge-preveiw-docs/README.md)。开发服务、类型生成、构建和运行测试应顺序执行；运行测试会重新构建应用产物，之后需为实际工作区重新 build。本次最终产物已重新构建为 MyyShop。

实施验收阶段未执行 Git commit/push。用户随后明确授权将本次阅读器改造、测试及相关文档提交并推送到远端，具体提交与推送范围以 Git 历史和当次授权为准。本任务未执行飞书同步、外部部署或发布，未批准知识事实，未启动 GEO 采样。构建模式是快照，修改源内容后需要重新 build；日常开发模式自动更新。完整 CSV 会产生较大的页面载荷，这是保留全文的当前实现，不截断材料。
