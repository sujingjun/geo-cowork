## 目标用户与价值

Owner 维护知识事实、原始证据和必要决定。Agent 完成问题准备、观察接收、诊断、建议、反馈处理、复测与复盘，Owner 不维护内部 ID、hash、状态或编排 JSON。

## 产品旅程

业务知识和需求线索 → 候选问题与选择 → 原始答案与分析 → Content/Evidence Gap 和 Own/External 诊断 → 可读建议 → 人工采用/修改/拒绝/延期 → 隔离发布读回 → 技术和平台复测 → Analytics → Cycle Review → 独立下一 Goal 选择 → 第二周期。

## 当前明确选择

- 当前宿主对话、Skill/CLI 与 Markdown 文件为入口。
- 提取全部使用真实模型，默认 DeepSeek；OpenAI-compatible 保留配置切换，当前无需公司网络真实验收。
- Query 支持人工导入、GSC 查询词及知识驱动生成，保留各自来源与未知信息。
- Playwright MCP 完成 ChatGPT、Gemini、Perplexity 各一次低频真实采集，作为工程验证，独立于正式双槽 Baseline。
- 两轮演练使用同 Merchant 的隔离测试知识库，每轮 120 个逻辑槽；原始外部模拟输入和真实模型执行明确区分。

## 验收与非目标

所有下游工件由实际入口生成，能按文件续跑；人工决定必须绑定所审核版本，修改后重新审核，缺证据不会被更强文案替代。零值、缺失、负向和不确定性保留。

真实品牌事实、真实发布、正式真实业务周期和业务效果不由演练结果替代。此次不自动提交 Git、部署、发布或同步飞书；旧过程文档与审批串行等待不能重新阻断已明确的目标。
