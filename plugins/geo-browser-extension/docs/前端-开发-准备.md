# 前端开发准备完成 ✅

## 🎉 已完成的后端功能

### 1. 数据库架构 ✅
- ✅ `stores` - 店铺授权信息
- ✅ `products` - 商品数据缓存
- ✅ `sites` - 生成的站点
- ✅ `site_products` - 站点商品关联

### 2. API 端点 ✅

#### 店铺相关
- `GET /api/stores` - 获取用户店铺列表
- `POST /api/stores` - 启动 Amazon OAuth 流程
- `POST /api/stores/[id]/sync` - 同步店铺商品数据

#### 商品相关
- `GET /api/products` - 获取商品列表（支持过滤）
  - 参数: `storeId`, `category`, `keywords`, `limit`

#### 站点相关
- `GET /api/sites` - 获取站点列表
  - 参数: `userId`, `status`
- `GET /api/sites/[slug]` - 获取站点详情（包含商品）

#### AI 工具
- `get_products` - AI 从用户店铺获取商品
- `generate_site` - AI 生成 GEO 友好站点

#### 辅助工具
- `POST /api/db/seed` - 初始化测试数据（仅开发环境）

### 3. 测试数据 ✅

运行 `pnpm dev` 然后 `pnpm db:seed` 即可初始化：
- 2 个测试用户
- 2 个测试店铺
- 20 个测试商品（12个科技 + 8个家居）
- 3 个测试站点（Grid、List、Hero 模板）

详细说明见：[docs/数据-初始化.md](./数据-初始化.md)

#### 任务 5: 站点渲染页面和组件 🔨

创建以下文件：

1. **站点列表页** `app/pages/sites/index.vue`
   ```vue
   <template>
     <div>
   ```

2. **站点预览页** `app/pages/sites/[slug].vue`

#### 任务 6: SEO/GEO 优化 🔍

在站点预览页添加 SEO：

```vue
<script setup lang="ts">
const { data: site } = await useFetch(`/api/sites/${slug}`)

useSeoMeta({
  title: site.value.seoTitle,
  description: site.value.seoDescription,
  ogTitle: site.value.seoTitle,
  ogDescription: site.value.seoDescription,
  ogImage: site.value.ogImage
})

// 添加产品 Schema.org
useSchemaOrg([
  defineProduct({
    name: product.title,
    image: product.imageUrl,
    description: product.description,
    offers: {
      price: product.price,
      priceCurrency: product.currency,
      availability: 'https://schema.org/InStock',
      url: `https://amazon.com/dp/${product.asin}`
    }
  })
])
</script>
```

## 📦 数据结构参考

### Site Object

```typescript
{
  id: string
  title: string
  slug: string
  theme: string
  template: 'grid' | 'list' | 'hero'
  status: 'draft' | 'published'
  seoTitle: string
  seoDescription: string
  ogImage: string | null
  publishedAt: Date | null
  createdAt: Date
  user: {
    id: string
    name: string
    username: string
    avatar: string
  }
  products: Product[]
}
```

```typescript
{
  id: string
  asin: string
  title: string
  price: string
  currency: string
  imageUrl: string
  description: string
  category: string

}
```

## 🐛 故障排除

**问题: API 返回空数据**
- 确保已运行 `pnpm db:seed` 初始化数据

**问题: 站点页面 404**
- 检查路由文件是否正确创建
- 确认 slug 参数正确

**问题: 图片无法加载**
- Unsplash 图片可能需要代理
- 可以替换为本地图片

**问题: SEO 标签不生效**
- 检查 `useSeoMeta` 是否正确调用
- 使用浏览器开发者工具查看 `<head>` 标签
