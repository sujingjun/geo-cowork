## 📝 已知问题和限制

### 1. 类型定义不完整
- **问题**: 某些 API 响应类型需要手动定义
- **解决方案**: 从数据库 schema 自动生成类型

### 2. 错误处理不够完善
- **问题**: 部分 API 调用缺少错误边界
- **解决方案**: 添加全局错误处理和用户友好的错误提示

### 3. 图片加载慢
- **问题**: Unsplash 图片加载速度取决于网络
- **解决方案**: 使用图片代理或 CDN 缓存

### 4. SEO 优化待验证
- **问题**: Schema.org 数据未经 Google 验证
- **解决方案**: 使用 Google Rich Results Test 验证
