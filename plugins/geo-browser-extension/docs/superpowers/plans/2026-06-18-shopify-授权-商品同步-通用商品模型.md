# Shopify 授权商品同步通用商品模型 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为现有 Nuxt AI Chatbot 增加 Shopify 店铺授权、商品同步和跨平台通用商品模型，支撑后续 AI 选品与 Shopify GEO 站点定制生成。

**Architecture:** 保留现有 `stores -> products -> sites` 主链路，把 Amazon 专用字段抽象为平台无关字段，并通过平台同步器分派 Amazon / Shopify。Shopify 接入采用 standalone OAuth callback，服务端保存 offline access token，再通过 Admin GraphQL API 同步商品。

**Tech Stack:** Nuxt 4, Nitro server routes, Drizzle ORM, PostgreSQL/PGlite, NuxtHub DB, TypeScript, Shopify Admin GraphQL API, Shopify OAuth authorization code grant.

## Global Constraints

- Node.js 22+，pnpm 9+。
- 数据库使用 Drizzle schema 和 `pnpm db:generate` / `pnpm db:migrate` 生成迁移。
- 所有 Shopify secret 只放在 runtime config / 环境变量中，不进入前端 public config。
- Shopify OAuth callback 必须校验 `state`、`hmac`、`shop` hostname。
- 第一阶段只请求最小权限：`read_products`。
- 保持现有 Amazon 授权和商品同步可用。
- AI 生成文档必须放在 `/docs`，文档名称使用中文 kebab-case。

## Current Context

现有代码已经具备 Amazon 店铺授权和商品站点生成雏形：

- `server/db/schema.ts`：`stores.platform` 目前只有 `amazon`，`products` 使用 `asin` 表示商品外部 ID。
- `server/api/stores.post.ts`：Amazon 授权发起端点。
- `server/routes/auth/amazon.get.ts`：Amazon OAuth callback。
- `server/api/stores/[id]/sync.post.ts`：同步逻辑写死 `getAmazonProducts`。
- `shared/utils/tools/get-products.ts`：AI 工具文案写死 Amazon。
- `shared/utils/tools/generate-site.ts`：复用 `products` 创建站点。
- `app/pages/sites/[slug].vue`、`app/components/site/*.vue`：商品链接和 JSON-LD 目前写死 Amazon 商品 URL。

Shopify 官方要求：

- OAuth 安装请求和 callback 需要验证 `hmac`，并校验 `state` nonce 和 `shop` hostname。
- 授权 URL 格式为 `https://{shop}/admin/oauth/authorize?...`。
- access token exchange 地址为 `POST https://{shop}.myshopify.com/admin/oauth/access_token`。
- Admin GraphQL 使用版本化路径，如 `/admin/api/2026-04/graphql.json`。

参考：

- Shopify OAuth authorization code grant: https://shopify.dev/docs/apps/build/authentication-authorization/access-tokens/authorization-code-grant
- Shopify Admin GraphQL products query: https://shopify.dev/docs/api/admin-graphql/latest/queries/products
- Shopify API versioning: https://shopify.dev/docs/api/usage/versioning

## Data Model

`stores` 扩展：

```ts
platform: text('platform', { enum: ['amazon', 'shopify'] }).notNull().default('amazon')
storeId: text('store_id').notNull()
storeName: text('store_name').notNull()
region: text('region').notNull().default('us-east-1')
marketplaceId: text('marketplace_id')
shopDomain: text('shop_domain')
scopes: text('scopes')
```

`products` 通用化：

```ts
externalProductId: text('external_product_id').notNull()
platformHandle: text('platform_handle')
productUrl: text('product_url')
vendor: text('vendor')
productType: text('product_type')
tags: jsonb('tags').$type<string[]>().notNull().default(sql`'[]'::jsonb`)
variants: jsonb('variants').$type<Array<{
  id: string
  title: string
  sku?: string | null
  price?: string | null
  currency?: string | null
  inventoryQuantity?: number | null
}>>().notNull().default(sql`'[]'::jsonb`)
rawData: jsonb('raw_data').$type<Record<string, unknown>>().notNull().default(sql`'{}'::jsonb`)
```

兼容策略：

- 保留 `asin` 字段一个版本，作为 legacy alias，不立即删除。
- Amazon 同步同时写入 `asin` 和 `externalProductId`。
- Shopify 同步写入 `externalProductId = Shopify product GID`，`platformHandle = handle`。
- 新代码统一读 `externalProductId` / `productUrl`。

## Risks

- Shopify OAuth 安全校验遗漏会造成授权风险；必须覆盖 `hmac`、`state`、`shop`。
- 商品模型迁移影响 Amazon 现有逻辑；保留 `asin` 一个版本降低风险。
- Shopify 商品价格、库存、币种在多市场场景可能复杂；MVP 只同步默认 price range 和前 10 个 variants。
- 写入 Shopify Page / Theme App Extension 不在本计划范围内，后续另开计划。

## Out of Scope

- 发布 GEO 页面到 Shopify Pages。
- Theme App Extension。
- Shopify App Store 审核材料。
- 订单、销量、利润数据分析。
- 多语言、多市场、本地化价格。
