# 支持的 AI 模型列表

## 聊天模型

### OpenAI 模型

| 模型名称 | 模型 ID | 特点 | 推荐用途 |
|---------|---------|------|---------|
| GPT-4o | `openai/gpt-4o` | 最强性能，多模态支持 | 复杂任务、代码生成、多模态输入 |
| GPT-4.1 | `openai/gpt-4.1` | 平衡性能和成本 | 日常对话、中等复杂度任务 |
| GPT-4o Mini | `openai/gpt-4o-mini` | 快速响应，高性价比 | 简单对话、标题生成、快速响应 |
| GPT-4.1 Mini | `openai/gpt-4.1-mini` | 轻量级模型 | 简单任务、低成本场景 |

### Anthropic 模型

| 模型名称 | 模型 ID | 特点 | 推荐用途 |
|---------|---------|------|---------|
| Claude 3.7 Sonnet | `anthropic/claude-3-7-sonnet` | 高性能，推理能力强 | 复杂分析、长文本处理、专业写作 |

### DeepSeek 模型

| 模型名称 | 模型 ID | 特点 | 推荐用途 |
|---------|---------|------|------|
| DeepSeek V4 Pro | `deepseek/deepseek-v4-pro` | 高性能推理，中文友好 | 复杂代码生成、深度分析、专业写作 |
| DeepSeek V4 Flash | `deepseek/deepseek-v4-flash` | 快速响应，超高性价比 | 日常对话、快速查询、简单任务 |

## 模型选择建议

### 性能优先
```
1. GPT-4o - 最强性能
2. Claude 3.7 Sonnet - 强推理能力
3. GPT-4.1 - 平衡选择
```

### 成本优先
```
1. GPT-4.1 Mini - 最低成本
2. GPT-4o Mini - 高性价比
3. GPT-4.1 - 中等成本
```

### 响应速度优先
```
1. GPT-4o Mini - 最快响应
2. GPT-4.1 Mini - 快速响应
3. GPT-4.1 - 中等速度
```

## 默认配置

项目默认使用 **GPT-4o Mini** 作为标题生成模型，平衡了速度和成本。

用户可以在界面中选择任何支持的模型进行对话。

## 更新模型列表

如需添加新模型，编辑 `shared/utils/models.ts`：

```typescript
export const MODELS = [
  { 
    label: '显示名称', 
    value: 'provider/model-id', 
    icon: 'i-simple-icons-provider' 
  }
]
```

## 模型限制

- **上下文窗口**: 各模型有不同的最大 token 限制
- **速率限制**: 取决于你的 API 配额
- **功能支持**: 某些功能（如工具调用）可能因模型而异

## 常见问题

**Q: 为什么看不到某些模型？**  
A: 只有在 `shared/utils/models.ts` 中配置的模型才会显示在界面中。

**Q: 如何添加更多模型？**  
A: 在 `MODELS` 数组中添加新的模型配置，确保模型 ID 正确。

**Q: Embedding 模型在哪里使用？**  
A: Embedding 模型目前未在聊天界面中使用，预留给未来的语义搜索功能。

**Q: 可以使用其他提供商的模型吗？**  
A: 当前支持 OpenAI 和 Anthropic。如需添加其他提供商，需要修改 `server/utils/ai-providers.ts`。
