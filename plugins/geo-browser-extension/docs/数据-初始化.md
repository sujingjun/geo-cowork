# 数据初始化指南

## 快速开始

### 1. 启动开发服务器

```bash
pnpm dev
```

### 2. 初始化测试数据

在另一个终端窗口中运行：

```bash
# 方式 1: 使用 npm 脚本
pnpm db:seed

# 方式 2: 直接调用 API
curl -X POST http://localhost:3000/api/db/seed
```

## 注意事项

⚠️ **重要提示**

1. 数据初始化只能运行一次
   - 如果用户已存在，API 会返回错误
   - 需要清空数据库后重新初始化

2. 开发环境限制
   - Seed API 仅在开发环境可用
   - 生产环境会返回 403 错误

3. 图片资源
   - 使用 Unsplash 作为图片来源
   - 图片 URL 格式: `?w=400&h=400&fit=crop`

## 清空数据库

如需重新初始化数据：

```bash
# 外部 PostgreSQL
psql "$DATABASE_URL" -c 'DROP SCHEMA public CASCADE; CREATE SCHEMA public;'

# 或本地 PGlite
rm -rf .data/db

# 重新运行迁移
pnpm db:migrate

# 重新初始化数据
pnpm db:seed
```

如果未设置 `DATABASE_URL` / `POSTGRES_URL` / `POSTGRESQL_URL`，NuxtHub 会自动使用本地 PGlite。

## 故障排除

**问题: seed 命令失败**
- 确保开发服务器正在运行 (`pnpm dev`)
- 检查端口 3000 是否被占用

**问题: 数据已存在**
- 清空数据库后重新初始化
- 或者手动删除测试用户

**问题: API 返回 401**
- 某些 API 需要用户认证
- 使用测试用户 ID 模拟登录
