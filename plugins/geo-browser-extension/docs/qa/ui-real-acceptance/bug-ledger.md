- 严重度：P1
- 首次发现：Round 01 / S2
- 复现率：1/1
- 环境：Chrome 152.0.7977.64 / Creator Workbench 1.0.0 / HEAD `764513756400ccf3a94357064fa3c5c9295bdb0a`

- 敏感信息处理：截图含公开账号资料，只保存在系统临时目录，不提交仓库。
- 初步归属：content / data / popup
- 阻塞场景：S2；会影响 S6 对当前页达人卡片的判断。
- 修复会话：`01a051ce-a07a-7e90-9b44-b240da9e21bf` / 修复 UI-001/002/004/005 TikTok 数据链路
- 修复 commit：`9a63ba4`、`f9b8abf`、`116d0c4`
- 针对性测试：主页/视频 owner 投影、全局完整发现、同页多批次聚合与新页面实例替换均通过；TikTok 聚焦 27/27，全量 84/84。
- 复验结果：Round 02 / S2，公开达人主页弹窗只显示当前达人；摘要、列表和本页总数均为 1，冷却期内未重复抢焦点。

### UI-002 TikTok 发现数据同步调用 fetch 时发生 Illegal invocation

- 状态：CLOSED
- 严重度：P1
- 首次发现：Round 01 / 环境准备与 S2
- 复现率：错误面板记录 3 次历史发生；本轮刷新已存在达人时未新增记录
- 环境：Chrome 152.0.7977.64 / Creator Workbench 1.0.0 / HEAD `764513756400ccf3a94357064fa3c5c9295bdb0a`
- 前置条件：扩展已经被动发现 TikTok 页面数据且配置了本地服务端地址。
- 最小复现步骤：在 `chrome://extensions` 打开 Creator Workbench 的错误面板，查看后台脚本错误。
- 预期：发现数据通过本地服务端入口同步，不产生后台脚本异常。
- 实际：错误面板记录 3 条 `[CreatorWorkbench] TikTok discovery sync failed: TypeError: Failed to execute 'fetch' on 'WorkerGlobalScope': Illegal invocation`，上下文为 `background.js`。
- 用户影响：TikTok 发现数据可能只保留在扩展本地，服务端持久化闭环失败。
- 截图/日志：Chrome 扩展错误面板；未清除历史错误记录。
- 敏感信息处理：记录只保留错误摘要，不复制页面数据或请求内容。
- 初步归属：service-worker / data
- 阻塞场景：服务端同步与进程重启后的数据闭环；不阻塞只读 UI 场景继续盘点。
- 修复会话：`01a051ce-a07a-7e90-9b44-b240da9e21bf` / 修复 UI-001/002/004/005 TikTok 数据链路
- 修复 commit：`9a63ba4`、`f9b8abf`、`116d0c4`
- 针对性测试：同步、评论分析、删除三条 Worker fetch 接收者测试通过；TikTok 聚焦 27/27，全量 84/84。
- 复验结果：Round 02，刷新扩展并完成主页、探索页被动发现及本地同步后，错误面板中的 3 条历史记录没有新增；可访问性文本计数保持 6 次（每条错误在按钮与正文各出现一次）。
