# 模型配置更新说明

## 更新内容

已将模型列表更新为实际支持的模型。

## 当前支持的模型

### OpenAI (4个模型)
- ✅ GPT-4o - 最强性能
- ✅ GPT-4.1 - 平衡性能
- ✅ GPT-4o Mini - 快速响应（默认用于标题生成）
- ✅ GPT-4.1 Mini - 轻量级

### Anthropic (1个模型)
- ✅ Claude 3.7 Sonnet - 高性能推理

### DeepSeek (2个模型) 🆕
- ✅ DeepSeek V4 Pro - 强大推理能力，高性价比
- ✅ DeepSeek V4 Flash - 极速响应，超低成本

## 已移除的虚构模型
- ❌ Claude Haiku 4.5
- ❌ Gemini 3 Flash
- ❌ GPT-5 Nano

## 环境变量配置

```env
# OpenAI (可选)
OPENAI_API_KEY=sk-proj-xxxxx
OPENAI_BASE_URL=https://api.openai.com/v1  # 可选

# Anthropic (可选)
ANTHROPIC_API_KEY=sk-ant-xxxxx
ANTHROPIC_BASE_URL=https://api.anthropic.com  # 可选

# DeepSeek (推荐 - 高性价比)
DEEPSEEK_API_KEY=sk-xxxxx
DEEPSEEK_BASE_URL=https://api.deepseek.com  # 可选

# Google (可选)
GOOGLE_GENERATIVE_AI_API_KEY=xxxxx
GOOGLE_BASE_URL=  # 可选
```

## 修复的问题

### ✅ 404 Not Found 错误
**原因**: 使用了不存在的模型名称 `claude-haiku-4.5`  
**解决**: 更新为真实的 `claude-3-7-sonnet`

### ✅ 模型验证失败
**原因**: 配置中的模型与 AI 提供商实际模型不匹配  
**解决**: 只使用经过验证的真实模型 ID

## 测试步骤

1. **重启开发服务器**
```bash
pnpm dev
```

2. **测试 OpenAI 模型**
   - 选择任意 GPT 模型
   - 发送测试消息
   - 验证响应正常

3. **测试 Anthropic 模型**
   - 确保设置了 `ANTHROPIC_API_KEY`
   - 选择 Claude 3.7 Sonnet
   - 发送测试消息
   - 验证响应正常

4. **测试标题生成**
   - 创建新聊天
   - 发送第一条消息
   - 验证自动生成的标题

## 模型使用建议

### 日常对话
推荐: **DeepSeek V4 Flash** 或 **GPT-4o Mini** - 快速响应，性价比高

推荐: **DeepSeek V4 Pro** 或 **GPT-4o** - 代码能力出色

### 成本优化
推荐: **DeepSeek V4 Flash** - 极低成本，性能出色
