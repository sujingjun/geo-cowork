# 🚀 DeepSeek 使用指南

## 快速开始（30秒配置）

```bash
# 1. 获取 API 密钥
# 访问 https://platform.deepseek.com/ 注册并获取

# 2. 配置环境变量
echo "DEEPSEEK_API_KEY=sk-你的密钥" >> .env

# 3. 测试配置
pnpm test:deepseek

# 4. 启动应用
pnpm dev
```

✅ 配置完成！在模型选择器中选择 DeepSeek 即可使用。

## 🔄 模型切换策略

### 智能混合使用
```typescript
// 快速查询 → Flash
"今天天气怎么样？" → DeepSeek V4 Flash

// 复杂任务 → Pro  
"重构这个 500 行的 React 组件" → DeepSeek V4 Pro

// 紧急快速 → Flash
"快速生成一个按钮组件" → DeepSeek V4 Flash

// 深度分析 → Pro
"分析这个架构的优缺点并提供改进方案" → DeepSeek V4 Pro
```

### 成本优化建议
1. **80% 使用 Flash** - 日常对话和简单任务
2. **20% 使用 Pro** - 仅在需要强推理时
3. **控制上下文** - 定期开启新会话，避免长对话
4. **使用流式响应** - 可随时终止不需要的回复

## 🎓 使用技巧

### 1. 提示词优化
```
❌ 不好: "帮我写代码"
✅ 更好: "使用 TypeScript 和 React Hooks 创建一个带表单验证的登录组件"
```

### 2. 上下文管理
```
💡 技巧: 每 10-15 轮对话开启新会话
原因: 减少 token 消耗，提升响应速度
```

### 3. 模型选择
```
简单任务 → Flash (快 + 便宜)
复杂任务 → Pro (强 + 准确)
```

### 4. 错误重试
```
如果响应不满意:
1. 重新生成（点击重试按钮）
2. 调整提示词更具体
3. 切换到 Pro 模型
```
