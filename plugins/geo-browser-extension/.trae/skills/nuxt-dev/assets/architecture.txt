## Key Architectural Decisions

1. **Full-Stack Framework**: Nuxt 4 provides both client and server in a single codebase
2. **Auto-Import**: Components, composables, and utilities are automatically imported
3. **File-Based Routing**: Pages directory structure defines routes automatically
4. **Server Routes**: API routes in server/api/ are automatically mapped to /api/* endpoints
5. **Streaming**: AI responses use Server-Sent Events (SSE) for real-time streaming
6. **Edge-First Database**: SQLite (local) and Turso (distributed SQLite for production)
7. **Modular Storage**: NuxtHub Blob supports multiple storage backends (Vercel Blob, R2, S3)
8. **Unified AI Access**: Vercel AI Gateway provides single API for multiple AI providers
