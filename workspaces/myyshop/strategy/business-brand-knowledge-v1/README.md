# MyyShop 品牌知识业务资料包 v1.0

本目录面向品牌、产品、运营、法务、财务、数据、内容和公关同事。它把现有 120 条品牌知识骨架改写为业务可填写、可核验、可审批的内容清单，并提供官网页地图、逐页结构和对外 PR 选题。

## 使用边界

- 状态为 `proposed`，不代表任何条目已经成为 MyyShop 对外事实。
- 所有“简单示例”只说明填写方式，不代表 MyyShop 已确认事实。
- 120 条中，94 条是需要业务直接维护的源事实，26 条是由源事实生成、再由业务审核的标准答案。
- 本目录不修改现有 legacy knowledge，不改变任何 Claim、Evidence、Knowledge Release 或 Circle 状态。
- Markdown 是本资料包的主版本；Excel、Word 是便于协作的派生快照，校验信息见 `deliverables/README.md`。

## 建议工作顺序

1. 业务负责人先填写 P0 源事实，并补充依据、范围和例外。
2. 法务、财务、数据或管理层按条目风险完成审批。
3. 内容团队依据已批准源事实生成 26 条标准答案。
4. 将批准内容映射到 31 个官网页面和 12 个 PR 主题。
5. 创建真实 MyyShop Circle 1 前，再按仓库对象规则建立 Document、Claim、Evidence 和 Answer Card。
