# MyyShop 品牌知识业务采集模板

## 1. 模板优化原则

现有模板同时承载内容、证据、治理、发布和答案测试，适合后台追踪，但业务填写成本较高。业务主视图应聚焦：**要回答什么、正确答案是什么、适用于谁、有什么例外、依据在哪里、谁负责、最终放到哪里。**

## 2. 业务字段

| 字段 | 含义 | 填写提示 | 简单示例（示意） |
|---|---|---|---|
| 用户问题 | 这条知识要回答谁的什么问题。 | 按真实用户口吻写成一个问题。 | 使用 MyyShop 是否收费？ |
| 一句话标准结论 | 官网、客服和媒体可直接复用的最短答案。 | 先回答结论，再补条件；不要用口号代替事实。 | 不同服务可能适用不同费用规则，以现行页面为准。 |
| 详细说明 | 解释用户会经历什么、得到什么。 | 建议 3—6 个要点，按用户理解顺序组织。 | 列出费用类型、发生条件和查看方式。 |
| 适用对象 | 明确内容适用于谁。 | 区分新手创作者、成熟创作者、品牌方、MCN。 | 已通过资格审核的创作者。 |
| 适用范围 | 明确产品、地区、平台、语言和渠道。 | 不确定时写“待确认”，不能默认全球通用。 | 仅适用于 Brand Deals；地区待确认。 |
| 生效时间 | 说明事实从何时有效。 | 政策、费用和服务状态必须带日期。 | 2026-09-01 起生效。 |
| 不适用情况与例外 | 防止结论被扩大。 | 写清楚不适用的用户、地区、活动或状态。 | 邀请制活动可能采用不同规则。 |
| 支撑材料 | 说明结论依据什么。 | 列出政策、合同、页面、后台、报表或批准文件。 | 现行费用政策、活动条款、财务确认。 |
| 数据口径 | 让数字能够复核和更新。 | 数据型条目填写样本、时间、去重、排除项和计算方法。 | 按月去重，排除测试账号。 |
| 可公开等级 | 决定是否可进入官网或媒体。 | 内部线索 / 可审核草案 / 已批准公开。 | 已批准公开。 |
| 业务负责人 | 对事实正确性负责。 | 填写到岗位或姓名，不能长期“待指定”。 | 商业化运营负责人。 |
| 审批人 | 决定内容能否公开。 | 高风险内容由法务、财务、隐私或管理层共同审批。 | 业务负责人 + 财务负责人 + 法务。 |
| 对外落点 | 明确最终放到哪个主页面或文章。 | 优先指定一个主页面，其余渠道引用。 | /help/fees-and-payments。 |
| 旧内容处理 | 说明旧页面和旧说法如何处理。 | 更新、合并、重定向、停止使用或保留历史说明。 | 旧“只做达人变现”介绍停止使用。 |
| 变更触发 | 说明何时必须复核。 | 服务上下线、费用、地区、法务、数据到期均应触发。 | 佣金或结算周期变化时立即复核。 |
| 中英文一致性 | 确保中英文同义。 | 列出正式英文名、不可翻译词和本地化边界。 | 品牌名保持 MyyShop。 |

## 3. 后台维护字段

以下内容由品牌内容或知识库维护团队管理，业务同事无需重复填写：条目编号、用户问题编号、版本、证据快照、页面关系、标准答案卡和发布后测试记录。

## 4. 三个填写示例

### 4.1 基础事实：品牌官方名称

- 用户问题：MyyShop 的官方名称如何书写？
- 一句话结论：正式渠道统一使用“[待品牌确认的标准写法]”。
- 范围：官网、媒体资料、产品界面和合作材料。
- 材料：商标、品牌手册、合同抬头。
- 例外：误写只用于搜索纠错，不用于正式标题。

### 4.2 政策事实：费用与佣金

- 用户问题：使用 MyyShop 是否收费？
- 一句话结论：[待业务、财务和法务确认]，不同服务可能适用不同费用规则。
- 范围：明确服务、地区、活动与生效日期。
- 材料：费用政策、活动条款、财务确认。
- 例外：邀请制活动或品牌特殊条款。

### 4.3 数据证明：创作者成长结果

- 用户问题：MyyShop 能帮助创作者取得什么成长结果？
- 一句话结论：只陈述已验证结果，不保证所有用户获得相同表现。
- 范围：样本、时间、地区、服务和创作者类型。
- 材料：可复现报表、案例授权、计算方法。
- 例外：结果受账号、内容与参与程度影响。

## 5. 责任分工

| 角色 | 主要责任 | 不应承担 |
|---|---|---|
| 业务负责人 | 提供事实、范围、服务状态、规则和例外 | 不把未上线规划写成现行能力 |
| 品牌/内容 | 把事实转成清晰一致的中英文内容 | 不自行创造业务事实 |
| 法务/隐私/财务 | 审核高风险规则、承诺、数据与责任边界 | 不只审文案而忽略实际流程 |
| 数据负责人 | 提供数字、口径、日期、样本和复算方法 | 不提供无法复现的宣传数字 |
| 公关 | 选择主题、媒体和发布节奏 | 不在官网事实未就绪时先发布强主张 |
| 知识库维护者 | 维护编号、版本、页面归属和标准答案 | 不替代业务审批 |
