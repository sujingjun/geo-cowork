# MyyShop 官网页地图与页面结构

## 1. 规划原则

1. 主页面承载完整事实，其他页面摘要并链接。
2. 高频标准答案优先作为相关页面 FAQ 模块。
3. 阶段 1 先覆盖品牌、核心服务、加入规则、费用付款、信任和帮助。
4. 没有可核验数据时不展示无法复现的数字。
5. 每个页面都明确受众、核心信息、证明和行动入口。
