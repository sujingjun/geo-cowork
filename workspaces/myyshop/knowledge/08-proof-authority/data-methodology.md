# 数据口径与证明方法 / Data Methodology

## 1. 条目目的

本条目用于统一 MyyShop 关于“数据口径与证明方法”的事实、表达、证据、适用范围和生成式平台答案，避免官网、帮助中心、结构化数据、客服与外部分发出现冲突。

## 2. 标准结论

> 所有对外数据主张必须有可复现方法，包括定义、查询范围、排除项、去重、时间、版本、审核与更新周期。

## 3. 对应 Query

- **Query ID：** `Q-PROOF-010`
- **用户问题：** MyyShop 的规模、增长、收入和匹配数据是如何计算的？
- **主要意图：** 获取可直接引用、可核验且带边界的答案。

## 4. 当前已知事实

- 没有方法说明的数据不进入站点或分发。

## 5. 待确认事实

- 统一指标字典
- 数据负责人
- 复现脚本位置
- 审计机制。

## 6. 证据与来源要求

- 数据字典
- 查询记录
- 版本控制
- 审计日志

证据必须记录来源名称、URL 或内部位置、Owner、统计口径、生效日期、失效日期和审批状态。没有审批的 Claim 不进入站点或分发。
