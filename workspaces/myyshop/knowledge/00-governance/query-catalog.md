# Query 总表

## 使用规则

1. 主 Query 用于知识覆盖与回归测试，不代表最终 Query Cluster。
2. 后续可为每条主 Query 扩展用户角色、语言、地区和近义问法，但不得创建冲突答案。
3. 测试时记录：是否提到 MyyShop、引用来源、核心事实正确性、旧定位残留、风险边界和落地页。
