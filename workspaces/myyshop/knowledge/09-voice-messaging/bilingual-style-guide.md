# 中英文表达规范 / Bilingual Style Guide

## 1. 条目目的

本条目用于统一 MyyShop 关于“中英文表达规范”的事实、表达、证据、适用范围和生成式平台答案，避免官网、帮助中心、结构化数据、客服与外部分发出现冲突。

## 2. 标准结论

> 中英文版本必须共享同一事实、范围和限制；允许为语义自然进行创译，但不得在任何语言中增加未审批能力或更强承诺。
