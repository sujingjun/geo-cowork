## 1. 问题

Free Value Report 提供什么，是否永久免费？

## 2. 现状答案

Free Value Report 被介绍为 AI 辅助商业价值分析服务，涵盖赛道定位、受众画像、人设评估、同类标杆对比和潜在品牌机会。本次读取的是产品说明，未实际生成报告。 [S1](../../../../evidence/sources/src-myyshop-curation-20261022-report.md)

## 3. 详细说明与条件

- 报告页面同时显示“Limited-Time Free”和 USD 29.99。不能因为名称为 Free Value Report 就承诺永久免费，也不能把该展示金额用于所有 MyyShop 服务。 [S1](../../../../evidence/sources/src-myyshop-curation-20261022-report.md)
- 隐私政策说明会根据账号与活动信息进行人工或自动机会推荐，并描述请求解释、拒绝仅由自动化作出的决定及可能的人工复核等权利。本次未测试实际申请流程与响应表现。 [S2](../../../../evidence/sources/src-myyshop-curation-20261022-privacy.md)

## 4. 适用范围与限制

仅适用于所述服务及其介绍功能。本次读取了公开说明，未测试实际产品交付、全部市场和每个账号的访问资格。

## 5. 证据缺口与复核

- **G02**: 提供现行产品、国家、社媒平台与创作者资格矩阵，包括账号核验和例外；实际可用性与公开导航分别核实。
- **G05**: 确认零平台佣金、零提现手续费的适用范围，以及单独定价服务和限时优惠，包括 Free Value Report 与课程。
- **G17**: 在作出更强技术或效果表述前，确认 AI 能力、数据来源、模型或测量主张，以及解释或人工复核流程。
