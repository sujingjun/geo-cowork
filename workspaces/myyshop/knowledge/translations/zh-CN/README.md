# MyyShop 品牌知识库：中文对照

[English primary](../../README.md)

Version: 0.2.0 · 2026-10-22

英文是主要使用版本；本目录为完整简体中文阅读对照。120 个逻辑条目包括 94 条源事实和 26 条派生答案；全部为内部审核初稿。

## 如何使用

- 先阅读现状答案，再查看条件、证据和缺口。每条均链接到另一语言版本及支撑知识。
- 当前公开定位是本版基准。品牌定位是否改变尚未决定；本版不声称已完成或正在进行全生命周期平台转型。
- 编辑性知识问题用于组织材料，不是需求频次观察、正式 Query 或冻结 Query Set。
- 官网表述、已发布 PR 和官媒文案可证明对应来源说了什么；产品实际交付、当前适用性与业务批准分别核实。
- 原始材料保存在证据快照中。既有正式 Document、Claim、Release 和历史决定保持不变，不由这些初稿直接替代。
- 存在 canonical_target 时，它指向本次读取的公开参考页，不是已验证的 HTML canonical 标签，也不证明规划页面已发布。
