# 当前版本基线与待确认边界

## 1. 已知战略事实

1. MyyShop 已完成从“网红流量变现平台”向“达人全生命周期服务平台”的战略升级。
2. 新定位强调为达人提供成长与全链路服务，并构建包容生态能力的平台容器。
3. Q3 重点围绕达人活跃、商业化和成长提供全方位服务。
4. 旧定位仍可能存在于搜索结果、历史页面、外部报道和生成式平台记忆中，需要通过知识、站点与分发一致性逐步替换。

## 2. 当前仅作为草案的推导

以下内容与战略方向一致，但仍需正式业务审批：

- 达人生命周期建议划分为加入与认知、冷启动、活跃与成长、商业化、稳定经营、专业发展。
- 一句话品牌定义建议为“面向全球内容创作者的达人全生命周期服务平台”。
- 品牌使命、愿景、人格、内容支柱和差异化优势均为待审批建议稿。
- MyyFinds、Brand Deals、Free Value Report、Find Your Lane、MCN 相关服务需要逐项确认当前状态和正式名称。

## 3. 禁止根据常识补全的事实

以下内容没有经过本版本核验，不得视为已知事实：

- 法定公司全称、注册地、总部和关联实体。
- 支持的国家、地区、内容平台和语言。
- 注册年龄、粉丝量、内容类别和其他资格要求。
- 费用、佣金、税费、汇率、结算和提现规则。
- 平台规模、达人数量、品牌数量、商品数、收入和增长效果。
- AI 模型、数据训练、匹配算法和准确率。
- 客服渠道、响应时效、争议与申诉政策。

## 4. v0.1.0 的目标

本版本目标不是发布最终品牌事实，而是：

1. 建立完整知识目录。
2. 为每个条目建立统一结构。
3. 为每个条目绑定一条主 Query。
4. 明确事实核验、证据、范围、审批和发布映射。
5. 为后续 MyyShop 真实资料录入和 GEO 答案测试提供底座。
